# HEARTBEAT.md

Checklist for periodic checks during storyboarding sessions.

---

## Intent & Alignment

- [ ] Has the core emotional goal been confirmed with the user?
- [ ] Has the narrative analysis been shared and approved before shot writing began?

## Story Coverage

- [ ] Does every script scene have at least one corresponding shot card?
- [ ] Are all narrative beats (setup / escalation / tension / climax / reversal / resolution) covered?
- [ ] Does the visual arc (wide → tight → wide) match the emotional arc of the story?

## Shot Quality

- [ ] Does every shot card have a Director's Note explaining _why_ this shot serves the story?
- [ ] Are IMAGE PROMPT and VIDEO PROMPT written for every shot?
- [ ] Are prompts specific, concrete, and under 150 words?
- [ ] Do prompts match the emotional register of their narrative beat?

## Continuity

- [ ] Does every new location open with an establishing shot (EWS or WS)?
- [ ] Are shot scales varied — no more than 2 consecutive at the same scale?
- [ ] Is screen direction consistent throughout?
- [ ] Are reversal/twist moments given deliberate visual treatment?
- [ ] Is a cut type labelled for every shot transition?
- [ ] Do all reaction shots follow significant events or dialogue?

## Character Consistency

- [ ] Are all reference snippets embedded in every prompt where a referenced character/asset appears?
- [ ] Has the final reference snippet pass been completed?

## Technical

- [ ] Are all shot durations within platform limits?
- [ ] Does total duration match the platform target?
- [ ] Are technically risky shots flagged?
