# BOOTSTRAP.md — Session Startup

Run this checklist at the start of every storyboarding session.

---

## On First Load

1. Read `IDENTITY.md` — who you are and how you work
2. Read `SOUL.md` — your cinematography philosophy, genre vocabulary, and visual language
3. Read `USER.md` — the approved script, brief, and user's stated intent
4. Read `MEMORY.md` — past sessions, visual style preferences, lessons from failed shots
5. Read `AGENTS.md` — your role and full workflow
6. Read `/data/OPTIMIZATION.md` — universal rules that apply to all agents

---

## Intent Alignment (Do This Before Anything Else)

Before planning a single shot, confirm you have answers to:

- What is the **core emotional goal** of this piece? (What should the viewer feel by the end?)
- Who is the **audience** and where are they watching?
- What is the **format and platform**? (9:16 / 16:9 / 1:1, and duration target)
- What is the **tone**? (Serious / playful / epic / intimate / cinematic / raw)
- Are there any **visual references** (films, ads, styles)?
- Is the **narrative structure** linear, montage, character study, or hybrid?

If any of these are missing from `USER.md`, ask the user before proceeding. Summarise your understanding in 2–3 sentences and confirm alignment.

---

## Narrative Analysis Checklist

Once intent is clear, do this analysis before writing any shot cards:

1. Read the full script or story end-to-end
2. Identify the **visual anchor** — the one defining shot that captures the whole piece
3. Label every scene with its **narrative beat**: setup / escalation / tension / climax / reversal / resolution
4. Map all **locations** — plan an establishing shot for each
5. Sketch the **shot scale arc** — where do you open wide, push in close, pull back for impact?
6. Identify all **reversal or twist moments** — plan deliberate visual treatments for each
7. Set **screen direction** for each character
8. Decide the **pacing rhythm** — average shot duration, where to cut fast, where to breathe
9. Define the **visual signature** — one or two recurring elements that unify the piece

Share this analysis with the user before writing shot cards.

---

## Shot Card Requirements

Each card must include:

- Shot number, scene reference, timecode, duration
- Shot type (ECU / CU / MCU / MS / MWS / WS / EWS / OTS / POV / Aerial / Insert)
- Camera movement (Static / Pan / Tilt / Dolly / Truck / Handheld / Crane / Orbit / Zoom)
- Lens range and camera angle
- Composition notes
- Visual description and action
- Lighting mood
- Cut type to next shot — with reason
- Narrative function
- **Director's Note** — one sentence on _why_ this shot choice serves the story at this moment
- IMAGE PROMPT — shot type, angle, lighting, style, character snippet if applicable
- VIDEO PROMPT — shot type, camera movement, action, lighting, style, character snippet if applicable

---

## Delivery

- Run the full continuity self-check from `AGENTS.md` before saving
- Review total duration against platform target
- Present a summary table: Shot #, Scene, Duration, Type, Movement, Narrative Function, Director's Note
- Flag any shots that may be technically difficult to generate
- Note any visual risk areas (complex compositing, character likeness, unusual angles)
