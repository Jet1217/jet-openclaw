# BOOTSTRAP.md — Session Startup

Run this checklist at the start of every storyboarding session.

## On First Load

1. Read `IDENTITY.md` — who you are
2. Read `SOUL.md` — your cinematography philosophy and shot references
3. Read `USER.md` — the approved script and production brief
4. Read `MEMORY.md` — past sessions and visual style notes
5. Read `AGENTS.md` — your role and workflow
6. Read `/data/OPTIMIZATION.md` — universal rules that apply to all agents

## Before Storyboarding

1. Read the full script end-to-end — understand the complete narrative arc before planning a single shot
2. Identify the visual anchor — the one defining shot that captures the whole piece's essence
3. Map all locations — plan an establishing shot for each new location
4. Sketch the shot scale arc — where does the camera open wide, push in close, pull back for impact?
5. Mark reversal/twist moments — plan deliberate visual treatments for each
6. Decide screen direction for each character — keep it consistent throughout
7. Note any scenes requiring special camera movement, lighting, or cut type

## Shot Card Requirements

Each shot card must include:

- Shot number, scene reference, timecode, duration
- Shot type (ECU / CU / MCU / MS / MWS / WS / EWS / OTS / POV / Aerial / Insert)
- Camera movement (Static / Pan / Tilt / Dolly / Truck / Handheld / Crane / Orbit / Zoom)
- Lens range and camera angle
- Composition notes
- Visual description and action
- Lighting mood
- Cut type to next shot (match cut / smash cut / cross-cut / J-cut / L-cut / cutaway / reaction cut)
- Narrative function (establish / build tension / reveal / reaction / transition / payoff)
- IMAGE PROMPT — include shot type, angle, lighting, style, character snippet if applicable
- VIDEO PROMPT — include shot type, camera movement, action, lighting, style, character snippet if applicable

## Delivery

- Run the continuity self-check from AGENTS.md before saving
- Review total duration against platform target
- Present a summary table: Shot #, Scene, Duration, Type, Movement, Narrative Function
- Flag any shots that may be technically difficult to generate
