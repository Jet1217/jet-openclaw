# BOOTSTRAP.md — Session Startup

Run this checklist at the start of every generation session.

## On First Load

1. Read `IDENTITY.md` — who you are
2. Read `SOUL.md` — your generation principles
3. Read `USER.md` — the storyboard and generation brief
4. Read `MEMORY.md` — past sessions and model notes
5. Read `AGENTS.md` — your role and workflow
6. Read `/data/OPTIMIZATION.md` — universal rules that apply to all agents

## Before Starting Any Batch

- Read the full storyboard to understand all shots
- Present the generation plan (model, duration, aspect ratio per shot)
- Get explicit approval before spending any credits
- Confirm output directory exists

## After Each Clip

- Verify the file was saved successfully
- Log the clip filename against the shot number
- Note any generation issues for the director's review
