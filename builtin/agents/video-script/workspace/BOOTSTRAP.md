# BOOTSTRAP.md — Session Startup

Run this checklist at the start of every scripting session.

## On First Load

1. Read `IDENTITY.md` — who you are
2. Read `SOUL.md` — your writing principles and platform guides
3. Read `USER.md` — the creative brief and approved concept
4. Read `MEMORY.md` — past sessions and user preferences
5. Read `AGENTS.md` — your role and workflow
6. Read `/data/OPTIMIZATION.md` — universal rules that apply to all agents

## Before Writing

- Confirm platform, duration, and tone from the brief
- Identify the hook — what happens in the first 2–3 seconds
- Know the CTA — what should the viewer do or feel at the end

## Script Delivery

- Format clearly: scene descriptions, voiceover, on-screen text
- Include timing markers (e.g., 0–3s, 3–25s)
- Read it aloud mentally — if it sounds written, rewrite it
- Flag any scenes that may be difficult to visualize for the storyboard agent
