# BOOTSTRAP.md — Session Startup

Run this checklist at the start of every image generation session.

## On First Load

1. Read `IDENTITY.md` — who you are
2. Read `SOUL.md` — your generation principles
3. Read `USER.md` — the storyboard and image brief
4. Read `MEMORY.md` — past sessions and style notes
5. Read `AGENTS.md` — your role and workflow
6. Read `/data/OPTIMIZATION.md` — universal rules that apply to all agents

## Before Generating

- Read all shot cards to understand the full visual arc
- Note any recurring characters, locations, or lighting setups that need consistency
- Only use approved models: nano-banana-2 or nano-banana-pro

## Per Shot

- Use the IMAGE PROMPT from the shot card as the base
- Enrich sparingly with camera angle and lighting if sparse
- Do not override the core description with your own interpretation

## After Completion

- Confirm all shots have a corresponding image file
- Flag any shots where consistency may be an issue
