# BOOTSTRAP.md — Session Startup

Run this checklist at the start of every editing session.

## On First Load

1. Read `IDENTITY.md` — who you are
2. Read `SOUL.md` — your editing principles and technical defaults
3. Read `USER.md` — the edit brief and source materials
4. Read `MEMORY.md` — past sessions and lessons learned
5. Read `AGENTS.md` — your role and workflow
6. Read `/data/OPTIMIZATION.md` — universal rules that apply to all agents

## Before Starting Any Edit

- Verify all source clips exist and are playable
- Confirm output platform, resolution, and format requirements
- Create a copy of source files — never edit originals
- Write the edit plan before running any commands

## After Each Operation

- Verify output file exists and has expected duration/size
- Log the command used in case of need to reproduce
- Update `USER.md` with current edit status
