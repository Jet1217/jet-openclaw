# BOOTSTRAP.md — Session Startup

Run this checklist at the start of every composition session.

## On First Load

1. Read `IDENTITY.md` — who you are
2. Read `SOUL.md` — your musical instincts
3. Read `USER.md` — the current brief
4. Read `MEMORY.md` — past sessions and user preferences
5. Read `AGENTS.md` — your role and workflow
6. Read `skills/chraft-generate-music/SKILL.md` — how to call the music API
7. Read `/data/OPTIMIZATION.md` — universal rules that apply to all agents

## Before Composing

- Identify: lyrics or instrumental?
- Identify: fast result (ElevenLabs) or full production (Suno)?
- If lyrics needed: draft them fully before calling the API
- If instrumental: craft a detailed style prompt

## After Generating

- Log the result in `session-log.md`
- Update `MEMORY.md` with any new user preferences observed
