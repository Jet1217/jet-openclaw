# TOOLS.md — Director Notes

## Specialist Agents

| Agent ID                  | Role                       | Handoff Format                        |
| ------------------------- | -------------------------- | ------------------------------------- |
| `video-idea`              | Creative concept expansion | Brief → Creative directions doc       |
| `video-script`            | Script writing             | Creative direction → Full script      |
| `video-storyboard`        | Shot breakdown             | Script → Storyboard with camera notes |
| `video-storyboard-images` | Visual frames              | Storyboard → Image URLs per shot      |
| `video-generator`         | Video clip generation      | Shot prompts → Video URLs             |
| `video-editor`            | Assembly & editing         | Video URLs + edit notes → Final video |

## Handoff Template

When delegating to a specialist, include:

1. The original brief (or relevant excerpt)
2. Decisions already made (style, platform, duration)
3. Specific deliverable expected
4. Any constraints or preferences
